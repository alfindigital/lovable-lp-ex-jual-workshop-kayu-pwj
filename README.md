# LOVABLE LP EXAMPLE — Toko Kayu Purwojati

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

**Contoh edukatif** landing page yang dibangun dengan [Lovable](https://lovable.dev) untuk toko kayu/workshop kayu. Dibuat sebagai referensi teknis dan template open-source.

> ⚠️ **Template Edukasi** — Ganti semua informasi placeholder (nomor WA, alamat, nama toko) dengan data bisnis kamu sendiri sebelum deploy.

---

## Tentang Proyek Ini

Proyek ini adalah **demonstrasi** cara membangun landing page bisnis lokal menggunakan Lovable + TanStack Start. Stack yang dipakai:

- TanStack Start + TypeScript
- Tailwind CSS + shadcn/ui
- SEO-ready (meta tags, JSON-LD, sitemap)
- Mobile-first design

---

## Cara Pakai sebagai Template

1. **Fork** atau clone repo ini
2. **Ganti placeholder** di `src/routes/index.tsx`:
   - Nama toko
   - Nomor WhatsApp: cari `wa.me/...` → ganti dengan nomor kamu
   - Alamat dan jam buka
   - Foto produk di `public/`
3. **Deploy** ke Cloudflare Pages / Vercel / Netlify

---

## Quick Start

```bash
git clone https://github.com/alfindigital/lovable-lp-ex-jual-workshop-kayu-pwj.git
cd lovable-lp-ex-jual-workshop-kayu-pwj
npm install
npm run dev
```
